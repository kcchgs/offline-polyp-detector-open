# Contributing

This is an early documentation-stage project. Useful contributions include corrections to source citations, dataset provenance and access notes, reproducibility requirements, and clearly scoped evaluation-design improvements.

For a proposed change:

1. Explain the problem and link the primary source that supports the correction.
2. State the source version and the date checked. Preserve unresolved discrepancies.
3. Separate published evidence from proposed implementation and untested ideas.
4. Keep public documentation consistent about the absence of a released detector and clinical validation.
5. Review the complete diff for sensitive information and third-party material before proposing it.

Do not include patient-level material, identifiable screenshots, credentials, confidential institutional documents, unpublished third-party work, or dataset/model files. Examples should use synthetic values. Do not infer pathology or patient identities from images.

New implementation work should include reproducible environment information and tests. Any future model contribution needs its own provenance, dependency, data-permission, and weights-license review. It must not introduce clinical-performance claims without supporting evidence.

There is no clinical support service or response-time commitment. A public issue or pull request must not be used to report patient information or secrets. Follow the affected institution's or service provider's approved private reporting process for such incidents.
